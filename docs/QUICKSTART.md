# ARISE-I

**Your personal file organizer**

ARISE-I automatically organizes your messy folders into neat, categorized collections. Just one click and your files are sorted.

---

## Getting Started

### 1. Install ARISE-I

**Windows:**
1. Double-click `install.bat`
2. Wait for installation to complete
3. ARISE-I icon appears on your desktop

**Mac:**
1. Double-click `install.sh` in Terminal
2. Wait for installation to complete
3. ARISE-I appears in Applications

**Linux:**
1. Run `bash install.sh` in Terminal
2. Wait for installation to complete
3. ARISE-I appears in your applications menu

### 2. Launch ARISE-I

**Windows:** Double-click the ARISE-I icon on your desktop

**Mac:** Open ARISE-I from Applications

**Linux:** Search for "ARISE-I" in your applications menu

### 3. Organize Your Files

1. ARISE-I opens with your Downloads folder selected
2. Click the big blue **"✨ Organize Now"** button
3. That's it! Your files are now organized

---

## Features

### ✨ One-Click Organization
Just click "Organize Now" and ARISE-I sorts everything automatically.

### 🔄 Auto-Sort
Enable "Auto-sort new files" and ARISE-I watches your folder, organizing new files as they arrive.

### ↩️ Undo Made a mistake? Click "Undo Last" to restore everything.

### 📁 Any Folder
Click "Change" to organize any folder on your computer.

## Tips

- **First time?** Just use the default Downloads folder
- **Try it safely** - ARISE-I never deletes files, only moves them
- **Customize** - Create a config file to define your own categories
- **Batch organize** - Works on folders with thousands of files

---

## Need Help?

**Undo a mistake:** Click "↩️ Undo Last"

**Change folder:** Click "Change" next to the folder path

**Stop auto-sort:** Uncheck "Auto-sort new files"

**Advanced options:** Run `arise-i --help` in terminal

## Technical Details

- **Requires:** Python 3.10+
